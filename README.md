📦 Customer Service - E-Commerce Microservices

customer is a microservice responsible for managing customer-related data in a distributed e-commerce system.

🔧 Features

Create a new customer

Update customer details

Retrieve customer information by ID

Centralized exception handling

Check User have exited

Integration with other services via Eureka Discovery

🛠️ Technologies

Java 17
Spring Boot
Spring Web
Spring Data MongoDB
Spring Cloud (Eureka Discovery Client, Config Clint)
MapStruct
Lombok
